# 🤖 Criando Artigos com Inteligência Artificial

Projeto desenvolvido como parte de um desafio da DIO, com o objetivo de utilizar ferramentas de Inteligência Artificial para auxiliar na criação de conteúdos sobre tecnologia.

## 📚 Sobre o projeto

Este projeto apresenta os prompts utilizados na criação de um artigo sobre a linguagem C.

O tema escolhido foi:

**Funções na Linguagem C: entenda como elas ajudam a organizar seu código.**

## 📝 Artigo

O artigo explica de forma simples o que são funções, por que elas são importantes e como podem ajudar a organizar e reutilizar o código.

🔗 **Link do artigo:** https://web.dio.me/articles/funcoes-na-linguagem-c-entenda-como-elas-ajudam-a-organizar-seu-codigo-e3f131187998?back=/articles

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar:

* Criação de artigos com Inteligência Artificial;
* Criação de prompts;
* Estruturação de conteúdos;
* Criação de imagens para artigos;
* Organização de projetos no GitHub.
